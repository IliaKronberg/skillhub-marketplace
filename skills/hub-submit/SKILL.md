# Отправка скила в SkillHub

Этот скил не решает задач сотрудника. Он отправляет в хаб скил, который сотрудник
записал или поправил, чтобы ревьюер проверил его и выпустил для всех.

Адрес приёма хаба: https://fcba-2401-e320-c31-ff08-f0bd-fef5-9f4e-aed4.ngrok-free.app/v1/skills

## 1. Найти скил

- Возьми `SKILL.md`, созданный или изменённый в этом разговоре.
- Если таких файлов несколько или нет ни одного, спроси сотрудника, какой отправить.
  Без явного выбора ничего не отправляй.
- Отправляется весь текст файла как есть, вместе с блоком `name` и `description`.
- Вложения (картинки, файлы) хаб в маркетплейс не публикует. Их не отправляй.

## 2. Проверить перед отправкой

- **Слаг** — поле `name` из блока в начале файла. Он должен состоять из строчных
  латинских букв, цифр и дефисов, до 64 символов. Если не подходит, предложи
  исправленный и спроси согласия. Тот же слаг у уже существующего скила означает
  правку этого скила, а не новый скил.
- **Название** — первый заголовок `# ` или короткое название от сотрудника,
  до 255 символов.
- Покажи сотруднику слаг, название и первые строки текста и спроси подтверждение.
- Хаб маскирует ИНН, КПП, номера счетов и карт, суммы с валютой, а при пяти
  и более совпадениях отклоняет скил. Если в тексте видны реальные данные такого
  рода, предложи убрать их до отправки.

## 3. Токен сотрудника

Администратор хаба выдаёт сотруднику небольшой JSON с полями `api_base_url`
и `token`. Скил отправляется с этим токеном.

- Ищи его в файле `~/.skillhub/config.json`, затем в `skillhub.json` в рабочей папке.
- Если файла нет, попроси сотрудника вставить JSON, который ему выдал администратор.
  Предложи сохранить его в `~/.skillhub/config.json` с доступом только для владельца,
  чтобы в следующий раз не спрашивать.
- Никогда не показывай токен в ответах и не записывай его в `SKILL.md` или другие
  файлы, кроме файла настроек.
- Если в JSON есть `api_base_url`, отправляй на `<api_base_url>/v1/skills`,
  иначе на адрес приёма выше.

## 4. Отправить

Запусти скрипт, подставив путь к `SKILL.md`, название, слаг и адрес. Ключ повтора —
отпечаток слага и текста: повторная отправка того же текста не создаст дубль.


```python
import hashlib, json, os, pathlib, urllib.error, urllib.request

SKILL_PATH = "path/to/SKILL.md"   # файл из шага 1
TITLE = "Название скила"           # из шага 2
SLUG = "slug-skila"                # из шага 2
URL = "https://hub/v1/skills"      # из шага 3

config_path = next(
    (p for p in [pathlib.Path.home() / ".skillhub/config.json", pathlib.Path("skillhub.json")] if p.exists()),
    None,
)
config = json.loads(config_path.read_text()) if config_path else {}
token = config.get("token") or os.environ.get("SKILLHUB_TOKEN", "")
if config.get("api_base_url"):
    URL = config["api_base_url"].rstrip("/") + "/v1/skills"

content = pathlib.Path(SKILL_PATH).read_text(encoding="utf-8")
body = json.dumps({
    "slug": SLUG,
    "title": TITLE,
    "content": content,
    "source": "cowork",
    "idempotency_key": hashlib.sha256(f"{SLUG}\n{content}".encode()).hexdigest(),
}).encode()

request = urllib.request.Request(URL, data=body, method="POST", headers={
    "Authorization": f"Bearer {token}",
    "Content-Type": "application/json",
    "Accept": "application/json",
    "ngrok-skip-browser-warning": "1",
})
try:
    with urllib.request.urlopen(request, timeout=60) as response:
        print(response.status, response.read().decode())
except urllib.error.HTTPError as e:
    print(e.code, e.read().decode())
except urllib.error.URLError as e:
    print("NETWORK", e.reason)
```


## 5. Сказать сотруднику, что вышло

Хаб отвечает JSON с полем `outcome`. Переведи его в одну понятную фразу:

| Ответ | Что сказать |
| --- | --- |
| `201`, `draft_created` | Скил отправлен. Ревьюер проверит его и выпустит в маркетплейс. |
| `proposal_created` | Правка к существующему скилу отправлена на проверку. |
| `conflict` | Правка отправлена, но скил тем временем изменили. Ревьюер разберёт её вручную. |
| `no_change` | Такой текст уже есть в хабе, отправлять нечего. |
| `skill_publishing` | Скил сейчас публикуется. Попробуйте отправить через несколько минут. |
| `409`, `skill_archived` | Скил в архиве, правку к нему отправить нельзя. Обратитесь к администратору. |
| `422`, `blocked` | Хаб отклонил скил: в нём слишком много персональных данных. Уберите их и отправьте снова. |
| `422`, `invalid_title` | Хаб не принял название или слаг. Предложи исправить и отправить снова. |
| `422`, `missing_department` | В хабе у сотрудника не указан отдел. Обратитесь к администратору. |
| `invalid_request` | Покажи сотруднику список ошибок из поля `errors`. |
| `401` | Токен недействителен или отозван. Обратитесь к администратору за новым. |
| `403` | У токена нет права отправлять скилы. Обратитесь к администратору. |
| `413` | Скил слишком большой для отправки. |
| `429` | Слишком много отправок подряд. Подождите минуту. |
| `NETWORK` или страница вместо JSON | Не удалось достучаться до хаба. Возможно, выход в сеть к адресу хаба не разрешён. Передайте текст ошибки администратору. |

Не повторяй отправку сам после отказа. Повтор с тем же текстом безопасен:
хаб вернёт прежний ответ и ничего нового не создаст.
