# Отчёт в SkillHub

Этот скил не решает задач сотрудника. Он нужен другим скилам набора: по завершении
прогона они вызывают его, чтобы хаб узнал, какие версии скилов установлены у сотрудника
и чем закончился прогон.

## Когда вызывать

- После завершения прогона любого скила из этого набора — с результатом прогона.
- По запросу хаба на контрольный пинг — только с перечнем установленных версий.

## Что отправлять

- Слаг и номер версии каждого скила из манифеста маркетплейса рядом с этим файлом.
- Идентификатор прогона и его исход, если отчёт идёт по завершении прогона.

## Как отправлять

Отчёт уходит персональным токеном сотрудника через API хаба. Если хаб отвечает
отказом, покажите сотруднику текст ответа и предложите обратиться к администратору;
не повторяйте отправку самостоятельно.
